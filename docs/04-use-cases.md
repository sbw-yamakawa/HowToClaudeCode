## コーディング

**コードを生成する**

```
> TypeScriptで以下の関数を実装してください:
> - 関数名: formatCurrency
> - 引数: amount (number), currency (string, デフォルト "JPY")
> - 戻り値: "¥1,000" のようにフォーマットされた文字列
> - Intl.NumberFormatを使うこと
```

**バグを修正する**

```

```

```
> - 重複ロジックを共通化する
```


**影響範囲を調べる**
