## コーディング

### コードを生成する

```
> TypeScriptで以下の関数を実装してください:
> - 関数名: formatCurrency
> - 引数: amount (number), currency (string, デフォルト "JPY")
> - 戻り値: "¥1,000" のようにフォーマットされた文字列
> - Intl.NumberFormatを使うこと
```

### バグを修正する

```
> 以下のエラーが発生しています:
> TypeError: Cannot read properties of undefined (reading 'map')
> src/components/UserList.tsx の34行目です。
>
> エラーが発生する条件と修正方法を教えてください。
```

### コードレビューをしてもらう

```
> src/services/payment.tsをレビューしてください。
> 特にエラーハンドリングとセキュリティ面で問題がないか確認してください。
```

### リファクタリング

```
> src/utils/date.tsの関数群をリファクタリングしてください。
> 以下の点を改善してください:
> - 重複しているロジックを共通化する
> - 関数名をより分かりやすくする
> - 型定義を厳密にする
> 既存のテストが通ることを確認しながら進めてください。
```

### テストを書く

```
> src/services/auth.tsのlogin関数のユニットテストを書いてください。
> Vitestを使ってください。
> 以下のケースをカバーしてください:
> - 正常系: 正しい認証情報でトークンが返る
> - 異常系: パスワード間違いで401エラー
> - 異常系: ユーザーが存在しない場合
```

### 依存関係を調べる

```
> src/api/orders.tsを修正する前に、このファイルを参照しているファイルを調べて
> 変更の影響範囲を教えてください。
```

## ドキュメント作成

### READMEを書く

```
> このプロジェクトのREADMEを書いてください。
> 含めてほしい内容:
> - プロジェクトの概要（1〜2文）
> - 主な機能
> - インストール手順
> - 基本的な使い方
> - 環境変数の一覧
> 日本語で書いてください。
```

### コメントを補完する

```
> src/services/以下の全ファイルのpublic関数にJSDocコメントを追加してください。
> 既存のコメントは変更しないでください。
> 日本語で書いてください。
```

### 仕様書を書く

```
> src/api/users.tsのエンドポイント一覧から、API仕様書をMarkdown形式で作成してください。
> 各エンドポイントについて以下を記載してください:
> - HTTPメソッドとパス
> - リクエストパラメータ
> - レスポンスの形式
> - エラーレスポンス
```

### 変更内容をまとめる

```
> git diff main...HEADの変更内容を確認して、
> プルリクエストの説明文を日本語で書いてください。
> 変更の背景・内容・テスト方法を含めてください。
```

### コードを説明してもらう

```
> src/middleware/rateLimit.tsの処理を説明してください。
> レート制限のアルゴリズムと、設定値の意味を教えてください。
```
