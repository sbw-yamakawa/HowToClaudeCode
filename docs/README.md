# Claude Code 使い方ガイド

Claude Codeは、ターミナルで動作するAIコーディングアシスタントです。
コードの生成・編集・レビューからドキュメント作成まで、開発業務を幅広くサポートします。

## このガイドの使い方

**初めての方（インストールから始める）:**
1. [00-getting-started.md](./00-getting-started.md) — インストール・初回起動
2. [01-basics.md](./01-basics.md) — 基本操作
3. [04-use-cases.md](./04-use-cases.md) — 実際の使い方例

**もっと使いこなしたい方:**
4. [02-intermediate.md](./02-intermediate.md) — 効果的なプロンプト・設定
5. [03-advanced.md](./03-advanced.md) — 応用機能（MCP・エージェント・フック）

## Claude Codeでできること（ひとこと）

- コードを書いてもらう、修正してもらう
- バグの原因を調べてもらう
- READMEや仕様書を書いてもらう
- リファクタリングやテストを任せる
- ファイルをまたいだ大規模な変更を依頼する
