# 01. 基本操作

このファイルで学べること:
- Claude Codeの起動・終了
- 基本的な会話の始め方
- よく使うコマンド
- ファイルの読み込み・編集の依頼方法

---

## 起動と終了

```bash
# プロジェクトディレクトリで起動
claude

# 終了
/exit
# または Ctrl+C
```

---

## 基本的な会話

`>` プロンプトに日本語で入力するだけです。

```
> README.mdを読んで、このプロジェクトが何をするものか教えてください

> src/index.tsにバグがあります。確認してください

> テストを実行して結果を教えてください
```

**ポイント:** 具体的に指示するほど良い結果が出ます。「直して」より「○○という問題があるので修正して」の方が精度が上がります。

---

## よく使うコマンド

| コマンド | 説明 |
|---------|------|
| `/help` | 使えるコマンドの一覧を表示 |
| `/clear` | 会話履歴をリセット（新しいタスクを始めるとき） |
| `/compact` | 長い会話を要約してコンテキストを節約 |
| `/cost` | 現在の会話にかかったコストを表示 |
| `/status` | モデルや設定情報を確認 |
| `/exit` | Claude Codeを終了 |

---

## ファイルを読ませる

```
> src/utils.tsを読んで、どんな関数があるか説明してください
```

複数ファイルも指定できます:

```
> src/auth.tsとsrc/user.tsを読んで、認証の流れを説明してください
```

---

## ファイルを編集させる

```
> src/utils.tsのformatDate関数にタイムゾーン対応を追加してください

> package.jsonにlintスクリプトを追加してください: "lint": "eslint src/**/*.ts"
```

Claude Codeは変更前に確認を求めます（`y` で承認、`n` でスキップ）。

---

## コマンドを実行させる

```
> npm testを実行して、失敗しているテストを教えてください

> git statusの結果を見て、コミットするべき変更をまとめてください
```

---

## 会話をリセットするタイミング

新しいタスクを始めるときは `/clear` で会話履歴をリセットしましょう。
古い会話が残っていると、Claudeが混乱することがあります。

```
/clear
> 次のタスク: ログイン機能を実装してください
```
