# 基本操作

## 起動と終了

```bash
claude       # プロジェクトディレクトリで起動
/exit        # または Ctrl+C で終了
```

## 基本的な使い方

`>` プロンプトに日本語で入力するだけ。

```
> README.mdを読んで、このプロジェクトが何をするものか教えてください
> src/index.tsにバグがあります。確認してください
> テストを実行して結果を教えてください
```

具体的に指示するほど精度が上がる。「直して」より「○○というエラーが出るので修正して」の方がいい。

## よく使うコマンド

| コマンド | 説明 |
|---------|------|
| `/help` | コマンド一覧 |
| `/clear` | 会話履歴をリセット |
| `/compact` | 長い会話を要約してコンテキストを節約 |
| `/cost` | 現在の会話コストを表示 |
| `/status` | モデルや設定を確認 |
| `/rewind` | 同じセッション内で過去の状態に巻き戻す |
| `/resume` | 別のセッションに切り替えて再開する |
| `/exit` | 終了 |

## よく使うショートカットキー

| キー | 説明 |
|------|------|
| `Ctrl+C` | 現在の入力・レスポンスをキャンセル |
| `Ctrl+D` | セッションを終了 |
| `↑` / `↓` | コマンド履歴をナビゲート |
| `Ctrl+R` | コマンド履歴を逆検索 |
| `Shift+Enter` / `\ + Enter` | 複数行入力（Enterで送信せず改行） |
| `Esc Esc` | `/rewind` メニューを開く |
| `Shift+Tab` | パーミッションモードを切り替え |
| `Alt+T` | 拡張思考（Extended Thinking）をトグル |
| `Ctrl+O` | ツール実行の詳細出力をトグル |

## ファイルを読ませる・編集させる

```
> src/utils.tsを読んで、どんな関数があるか説明してください
> src/auth.tsとsrc/user.tsを読んで、認証の流れを説明してください
```

```
> src/utils.tsのformatDate関数にタイムゾーン対応を追加してください
> package.jsonにlintスクリプトを追加してください: "lint": "eslint src/**/*.ts"
```

変更前に確認が入る（`y` で承認、`n` でスキップ）。

## コマンドを実行させる

```
> npm testを実行して、失敗しているテストを教えてください
> git statusの結果を見て、コミットするべき変更をまとめてください
```

## 会話リセットのタイミング

新しいタスクを始めるときは `/clear` でリセット。古い会話が残っていると混乱することがある。

## rewind と resume

### /rewind — 同じセッション内で巻き戻す

`Esc Esc` または `/rewind` で過去のチェックポイント一覧を表示。選択後に操作を選ぶ：

| 操作 | 説明 |
|------|------|
| Restore code and conversation | コードと会話の両方を巻き戻す |
| Restore conversation | 会話だけ戻す（コードはそのまま） |
| Restore code | コードだけ戻す（会話はそのまま） |
| Summarize from here | その地点以降の会話を圧縮してコンテキストを解放 |

**注意**: Bash コマンドによるファイル変更（`rm`, `mv` など）は追跡されない。

### /resume — 別のセッションを再開する

```bash
claude --continue          # 最新のセッションを再開
claude --resume            # セッション一覧から選んで再開
claude --resume <名前>     # 名前を指定して再開
```

セッション内でも `/resume` で別の会話に切り替えられる。

### 使い分け

| やりたいこと | コマンド |
|-------------|---------|
| 直近の変更を取り消して別の方法を試す | `/rewind` |
| 前回の作業の続きから始める | `/resume` または `claude --continue` |
| 機能Aの作業中に機能Bへ切り替える | `/resume` |
