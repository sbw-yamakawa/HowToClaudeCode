# git worktree 追加コンテンツ — デザインドキュメント

## 概要

Claude Code ハンズオン資料に git worktree の使い方を追加する。
対象ファイルは `02-daily-use.md`（ブランチ同時編集ユースケース）と `05-extend.md`（エージェント隔離実行ユースケース）の2ファイル。
各ファイルが独立して参照できるよう、それぞれ完結した内容として書く。

## 対象読者

- `02-daily-use.md` の読者: 日常的に複数ブランチを扱う開発者（中級者）
- `05-extend.md` の読者: エージェント並列実行を活用したい上級者

## ユースケース

両ファイルで以下を網羅する:

1. **複数ブランチの同時編集**（02-daily-use.md メイン）
   - feature ブランチ作業中にホットフィックスを別ワークツリーで対応
   - PRレビューのためにブランチを切り替えずにコードを確認

2. **エージェントへの隔離環境付与**（05-extend.md メイン）
   - サブエージェントを worktree 内で動かしてメインブランチを保護
   - 並列エージェント実行で各エージェントに独立したワークツリーを割り当て

## コンテンツ設計

### `02-daily-use.md` への追加

**配置:** 「セッション管理」セクションの直後・「次のステップ」の前

**セクション構成:**

```
## git worktree — 複数ブランチを同時に作業する

- Claudeに頼む（推奨）
  - 例: feature作業中にホットフィックスを対応したい旨を伝える
- 仕組み
  - worktreeの概念図（ディレクトリ構成）
  - git worktreeとブランチの関係
- 基本コマンド集
  - git worktree add / list / remove
- よくある使い方パターン
  - ホットフィックス対応
  - PRレビュー確認
  - 長期ブランチの並行維持
- 注意点
  - 同一ファイルの同時編集禁止
  - node_modules / .env の扱い
- クリーンアップ
  - 不要なworktreeの削除手順
  - git worktree prune
```

### `05-extend.md` への追加

**配置:** 「エージェント」セクション直後・「プラグイン」の前

**セクション構成:**

```
## git worktree — エージェントに隔離環境を与える

- Claudeに頼む（推奨）
  - isolation: "worktree" を使った指示例
- 仕組み
  - worktree + エージェント並列実行の概念図
  - メインブランチ保護のメカニズム
- ユースケース
  - 実装計画の並列実行
  - 破壊的変更の試験的実施
  - E2Eテスト用の隔離環境
- worktreeエージェントのライフサイクル
  - 作成 → 作業 → マージ or 破棄
- 注意点・トラブルシューティング
  - worktree残骸の掃除
  - コンフリクト発生時の対処
  - git worktree prune
```

## 文体・形式の方針

- CLAUDE.md の設計方針に従う:「Claudeに頼む」→「仕組み解説」の順
- コマンドはコピペで動く形で記載
- 概念図はASCIIアートまたはコードブロックで表現
- 注意点は「なぜいけないか」の理由を必ず付記
- 既存ドキュメントのトーン（技術的かつ親しみやすい日本語）を維持

## 成功基準

- 02-daily-use.md を読んだ開発者が worktree の基本操作を自力で実行できる
- 05-extend.md を読んだ開発者がエージェントに worktree を使わせる指示を書ける
- 両ファイルとも前のファイルを読んでいなくても理解できる
- 各コマンドがコピペで動作する
